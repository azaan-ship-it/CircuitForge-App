**Build circuits. Code them. Watch them work.**

A ByteForge Studios app.

## Download

**[Download CircuitForge for Windows](https://github.com/azaan-ship-it/CircuitForge-App/releases/latest/download/CircuitForge-Setup-1.0.0.exe)**

Or grab it from the [Releases](https://github.com/azaan-ship-it/CircuitForge-App/releases) page. Windows may show a SmartScreen warning because the app isn't signed yet: click **More info → Run anyway**.

## Features

- **8 boards**: ESP32, ESP32-S3, ESP32-C3, NodeMCU (ESP8266), Arduino Uno, Nano, Mega and Raspberry Pi Pico, each with its real pin layout
- **4 ways to program**: Logic Lab (no code), Blocks, Simple code, or real Arduino C++
- **Real parts**: LEDs, RGB LEDs, buttons, servos, buzzers, an 8x8 LED matrix, DHT11, ultrasonic, MPU6050, RFID, logic gates and more
- **Helpful warnings** for LEDs with no resistor, short circuits and floating pins
- 17 examples with lessons, a serial monitor, live controls while your code runs
- Accounts, cloud saves and a Community gallery to like and remix builds
